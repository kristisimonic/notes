## Week 1 - History of Writing
- Cuneiform is one of the earliest known writing systems.
- One writing system can be used to write different languages.

## Week 2 - Bits and Bytes
- A bit represents a binary value of either 0 or 1.
- One byte contains 8 bits.

## Week 3 - Markdown
- Markdown uses # symbols to create headings.
- Links use the format [text](URL).

## Week 4 - Files and Data
- File extensions help identify the type of a file.
- Files and folders help organize information on a computer.

## Week 5 - Command Line and SSH
- The command line allows users to interact with a computer using text commands.
- SSH allows secure remote access to another computer.
